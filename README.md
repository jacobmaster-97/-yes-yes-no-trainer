# Yes–Yes–No｜第一身個人訓練紀錄 V2.0

單一 HTML、可離線使用的個人棒球訓練工具。V2 按最新需求改為：**第一身追蹤來球 → 投球後由你自評正確／錯誤 → 再揭示系統獨立記錄的好壞球**。

預設每組 20 球，出手球速隨機介乎 **50–80 km/h**。沒有遊戲分數、連擊、輸贏，也不會因為你未即時按鍵而判錯。

## 開啟程式

- 下載 `yes-yes-no-trainer.html`，在電腦以瀏覽器開啟即可，毋須安裝或建置。
- GitHub：**Code → Download ZIP** 可下載整個專案；或在 HTML 檔案頁按 **Download raw file**。
- 全部 HTML、CSS、JavaScript、Canvas/SVG 圖像均內嵌，沒有 CDN、外部圖片、字體、音效、後端或登入。
- 如受管理瀏覽器禁止 `file://`，可選擇以靜態伺服器開啟，例如 `python3 -m http.server 8000`，再到 `http://localhost:8000/yes-yes-no-trainer.html`。
- iPad 的「檔案」Quick Look 預覽未必執行 JavaScript；請用可執行本機 HTML 的開啟方式，或以 Safari 開啟同一份 HTML 的靜態網站版本。網頁載入後可斷網訓練，但本版未提供 PWA 離線重新載入保證。

GitHub 保存程式版本；你已下載的 HTML 不會自動更新。

## 每球操作

1. 調整球速、距離和好球帶；按「開始這組訓練」。
2. 按「開始投球」或 Enter。投手預備 1.1 秒後出手。
3. 以第一身視角追蹤整條來球；可以自行練習判斷或身體動作，程式不要求在來球途中按答案。
4. 球通過本壘後，按 **「自評正確」或「自評錯誤」**。這個選擇由你決定，不會被程式自動評分覆蓋。
5. 自評後才顯示系統的好／壞球、攻擊／保護區、落點、出手及到壘球速和實際模型飛行時間。
6. 可選填這球「出棒／放過」及筆記，或按「更改自評」修正自己的紀錄。
7. 按「下一球」。最後一球自評後整組自動保存，再按「查看整組紀錄」。

未自評時可一直等待，不會逾時判錯；下一球會等你完成自評。按「結束並保存」可保存已投的部分訓練，包括未自評的球。

### 按鍵與觸控

| 操作 | 鍵盤 | 滑鼠／iPad 觸控 |
|---|---|---|
| 開始／下一球／查看整組 | Enter | 對應按鈕 |
| 投後自評正確 | 1 | 自評正確 |
| 投後自評錯誤 | 2 | 自評錯誤 |
| 暫停／繼續 | P | 暫停／繼續 |
| 重看球路 | — | 重看本球 |
| 修改已作自評 | — | 更改自評 |

球仍在飛行、暫停或輸入筆記期間不接受自評快捷鍵。連續按鍵不會新增同一球的重複紀錄。重看會沿用同一條球路，不新增球數，也不重設已作的自評。切換分頁會自動暫停；暫停時球及飛行時間一併凍結。

「出棒／放過」是投後的選填紀錄，不是安打／揮空／三振判定。本版沒有追蹤身體或球棒，**不量度真實反應時間或擊球率**，也不會把投後按自評所花的時間當作揮棒反應時間。

## 第一身視角與球速

### 可調設定

| 設定 | 預設／範圍 |
|---|---|
| 每組球數 | 20；可選 10、20、30、50 |
| 出手球速 | 50–80 km/h；上下限各可設 40–180 |
| 投手板至本壘 | 18.44 m；可調 8–24 m |
| 放球延伸 | 1.8 m；可調 0–2.5 m |
| 放球點至本壘 | 前兩項之差，預設 16.64 m |
| 放球高度 | 1.8 m；可調 1.2–2.3 m |
| 視線高度 | 1.65 m；可調 1.2–2.0 m |
| 打者視角 | 中性；可選右打／左打 |
| 空氣阻力 | 預設開啟 |

V1 的「以動畫時間換算等效球速」已改為 V2 的**設定出手速度，計算飛行時間**：

- 球的初始三維速度長度等於設定 km/h ÷ 3.6；不是把螢幕位移乘以一個速度係數。
- 以重力 `9.81 m/s²`、可選二次空氣阻力 `a_drag = -k × |v| × v`，求解能到達預先選定落點的低仰角球路；預設 `k = 0.006 m⁻¹`。
- 使用 RK4、每步 1/240 秒積分；球路和到壘時間在每球開始前已確定。
- 動畫按 `requestAnimationFrame` 的實際經過時間，在數值軌跡內插，沒有刻意慢放、末段突然改落點或用固定幀數拖長飛行。
- 場地、投手、球與可選好球帶均採同一米制三維座標透視投影。球接近時按透視自然放大，不是從上帝視角看一條示意直線。
- 預設 50–80 km/h 並非固定飛行時間；落點高度、實際抽到的出手球速和阻力都影響到壘時間。到壘球速另行記錄。
- 若設定的低速及長距離無法在模型中到達所選落點，會提示調整，**不會偷偷提高球速或延長動畫假裝成功**。

這是物理模型的 1:1 時間播放，不是聲稱完全重現每位真實投手。模型未加入縫線、旋轉／Magnus 力、風、完整投手動作或真實球種辨識；慢速遠距離的球可能需要較高弧線。最小球體畫面半徑為 1.35 CSS 像素以確保可見。螢幕尺寸、觀看距離、幀率及輸入設備也會影響實際感受。

## 自評與系統好壞球分開保存

### 你的紀錄

- `selfRating: true / false / null`：自評正確、自評錯誤、未自評。
- `userAction: GO / NO / null`：自行填寫出棒、放過或未記錄。
- `note`：每球筆記；整組另有筆記。
- **自評正確比例**＝自評正確球數 ÷ 已自評球數。未自評不當錯誤，也不放進分母；分母為零顯示「未有樣本」。

### 系統在本機背景計算

「後台」在這個離線版本指本機程式的計算邏輯，沒有另設雲端伺服器。

- 好球帶寬固定為 0.4318 m；預設高度下緣 0.5 m、上緣 1.4 m，兩者可獨立修改。
- 球心落點採本壘平面上的米制座標 `endpoint.x`（左右）和 `endpoint.y`（離地高度）。
- 球半徑 0.0366 m；球體截面與好球帶矩形相交便記為 `isStrike: true`，包括擦邊；角落使用圓至矩形距離判斷，不把整個外擴矩形一律當好球。
- 可攻擊區預設為好球帶寬高的 65%，保護區為 115%，各自保存 `isAttackable`、`isProtectable`，不會混為好球帶。
- 兩好球設定只改變參考保護區及 `systemRecommendation`；不會改動 `isStrike` 或你的 `selfRating`。
- 近身危險區另作旗標，參考建議一律優先安全放過。
- 每球飛行完便保存系統分類和未自評紀錄；**先自評才在 UI 揭示該球系統結果**。側欄好壞球累計也只計已自評球，避免透過數字提前洩露分類。

系統好壞球是這個模型下的幾何判定，不是裁判判決；「好球」也不等於「你這球的訓練必定正確」。你可按自己的身體動作、準備及判斷目標自評。

## 本機資料、續練及匯出

- 新資料鍵名：`yyn-trainer-v2`；最近最多 40 組已保存的完整／部分訓練，另保留一組未完成草稿。
- 每球飛行完即保存；每次自評、行動及筆記修改也會保存。重新開啟後，可在首頁「繼續未完成的訓練」。
- 若關閉頁面時球尚在飛行，該球未算已投；續練會以原有種子重投同一球。若已飛完但未自評，續練直接回到待自評畫面。
- 「結束並保存」將已投球保存為部分紀錄。未自評球保留 `null`，沒有自動補成正確或錯誤。
- 總結提供本組 JSON／CSV；首頁可匯出所有 V2 紀錄及草稿。CSV 使用 UTF-8 BOM 和公式開頭防護。
- JSON／CSV 分別包含自評、好壞球及攻擊／保護旗標，另記錄出手／到壘速度、飛行時間、初速向量、放球點及落點等。CSV 只匯出表格欄位，完整物理設定及向量請看 JSON。
- 不把逐幀軌跡存入每組歷史，降低本機儲存空間需求；相同設定及種子可重建相同球路。
- `file://`、無痕模式及不同瀏覽器的儲存政策各異。若保存失敗會顯示提示，仍可練習及匯出；離開前請備份。
- 本版未提供 JSON 匯入或雲端同步。換檔案路徑、網址或瀏覽器，可能變成另一個儲存空間。

### V1 升級

舊鍵名 `yyn-trainer-v1` 不會被改寫或刪除。若在同一儲存來源找到舊紀錄，首頁提供 V1 備份 JSON；V1 的自動評分不會被當作 V2 的個人自評。清除 V2 紀錄也不會清除 V1。

若你的新 HTML 放在另一個路徑，瀏覽器未必讓它讀到舊檔案的資料。升級前可先在舊程式匯出 JSON 備份。

## 測試及持續修改

單純訓練不需要 Node.js。開發及測試使用 Node.js 20+：

1. `npm ci`
2. `npx playwright install chromium`
3. `npm test`

已有系統 Chromium 可設定 `CHROMIUM_PATH`。測試涵蓋 20 球流程、自評與系統分類獨立、未自評不逾時、重複按鍵、重看、暫停、草稿續練、筆記、匯出、V1 保留、無樣本分母、iPad 尺寸觸控及旋轉、儲存失敗和物理數值驗證。

無阻力飛行時間會與獨立解析彈道解交叉核對；並驗證初速向量長度、能量關係、逐點連續性、固定種子及球體擦邊分類。

測試環境的 Chromium 管理政策禁止 `file://`，因此以本機 HTML 攔截載入，並在瀏覽器離線狀態執行。這驗證無外部資源依賴，不等於實體 iPad／Safari 或本機雙擊已完成驗收；觸控測試使用 Chromium 模擬。實際流暢度仍受裝置限制。

開啟時加 `?debug=1` 可顯示當球落點及系統分類，並提供唯讀取樣工具 `YYN_DEBUG`；正常訓練預設關閉。**Debug 會提前顯示結果，只供開發驗證。**

詳見 [持續修改方式](docs/DEVELOPMENT.md)、[V2 設計及資料](docs/v2-design.md)。`docs/specification.md` 是最初 V1 規格，若有衝突，以目前使用者需求和 V2 說明為準。
