# Yes–Yes–No 棒球出棒判斷訓練｜V1.0.1

繁體中文、單一 HTML、原生 HTML/CSS/JavaScript + SVG。沒有 CDN、外部圖片、字體、音效檔、後端或登入，所有訓練邏輯都在本機執行。

## GitHub 版本與後續修改

本倉庫保存 km/h 更新版原始碼、最初規格及自動化測試。可直接修改根目錄的 `yes-yes-no-trainer.html`，不需要建置。GitHub 網頁中按 **Code → Download ZIP** 可下載整個專案；解壓後開啟 HTML。

若只要單一檔案，開啟 HTML 檔案頁後使用 GitHub 的 **Download raw file**。GitHub 的原始碼預覽頁不會執行訓練程式。

以後每次修改可建立分支、提交及 Pull Request，以保留差異和回復點。詳見 [持續修改方式](docs/DEVELOPMENT.md)。自動化測試：`npm ci`、`npx playwright install chromium`、`npm test`；這些工具只在開發時使用。

## 開啟與開始

1. 將 `yes-yes-no-trainer.html` 下載到電腦。
2. 以 Chrome、Edge、Firefox 或 Safari 開啟該檔案。一般桌面瀏覽器可直接雙擊／拖入開啟，毋須安裝依賴或啟動伺服器。
3. 預設為 **20 球標準決策**。按「進入練習」，再按「開始投球」或 Enter。
4. 投手先預備，球出手後才可選 GO／NO。球抵達本壘前會關閉決策視窗。
5. 本球抵達後會揭示落點、答案、原因及反應時間。按 Enter／「下一球」繼續。
6. 第 20 球後按「查看本組總結」。完整紀錄已在最後一球完成時儲存。

可在載入後關閉網絡繼續練習；程式運作不需要任何遠端服務。README 不必與 HTML 放在一起。

如瀏覽器管理政策禁止 `file://`，亦可將 HTML 放在任意靜態伺服器；沒有建置步驟。例如電腦已有 Python 時，在檔案所在資料夾執行 `python3 -m http.server 8000`，然後開啟 `http://localhost:8000/yes-yes-no-trainer.html`。這是可選的替代開啟方法，不是執行依賴。

### iPad

- 使用大尺寸 GO／NO 按鈕直接觸控；橫向優先，也支援直向及旋轉。
- iPad「檔案」App 的 Quick Look 預覽未必執行 HTML 內的 JavaScript。請使用支援本機 HTML/JavaScript 的開啟方式，或把相同 HTML 放在靜態網站，用 Safari 開啟。
- 網頁一旦載入，本組訓練不需要網絡；但本版沒有 Service Worker，**不保證 Safari 能在斷網後重新載入網站 URL**。要反覆離線開啟，須保留本機 HTML 並用可執行它的瀏覽器／檢視器。
- 全螢幕由瀏覽器提供；如 Safari 不支援或拒絕要求，程式會提示，仍可正常訓練。

## 操作

| 操作 | 鍵盤 | 滑鼠／觸控 |
|---|---|---|
| GO 出棒 | Space 或 J | GO 大按鈕 |
| NO 放過 | N 或 K | NO 大按鈕 |
| 開始／下一球／查看總結 | Enter | 開始／下一球按鈕 |
| 暫停／繼續 | P | 暫停／繼續按鈕 |
| 全螢幕 | — | 頁頂全螢幕 |

每球只接受一次有效選擇，按住鍵盤的重複事件也會被忽略。在預備前、投手預備期間、逾時、暫停及回饋後，GO／NO 都不會新增紀錄。輸入設定時，訓練快捷鍵不會干擾輸入框。投球途中切到其他分頁，會自動暫停。

暫停會凍結動畫及反應計時；已作出的選擇會保留。若啟用自動下一球，也可暫停回饋倒數。重設本組及離開未完成訓練會先顯示確認視窗；取消後回到原有暫停狀態。

## 模式及設定

- **慢速教學**：預設飛行 2600 ms，開啟第一個 YES／第二個 YES 提示。
- **標準決策**：預設 20 球，飛行 1800 ms，不揭示作答答案。
- **兩好球保護**：使用較大的保護區評分；也可在其他模式獨立勾選兩好球評分。
- 球數：10、20、30、50 球。
- 等效球速：教學約 25.5、標準約 36.9、進階約 60.3 km/h。保留原有 2600、1800、1100 ms 的飛行時間。
- 選「自訂 km/h／飛行時間」，在「時間、保護區及重試設定」輸入約 13.3–94.8 km/h 或 700–5000 ms；另一欄自動換算。球速顯示取小數一位，內部保留未捨入的飛行時間。
- 投手預備約 850 ms；飛行時間自「球出手」開始計。
- 決策截止：可調飛行時間的 55–90%，預設 75%。標準設定為出手後 1350 ms，早於抵達本壘的 1800 ms。
- 好球比例：0–100%，按 `round(球數 × 比例)` 生成該組的好球數，再洗牌。比例表示模擬好球，**不是**必須選 GO 的比例。
- 可攻擊區：預設好球帶寬、高的 65%，可調 35–100%。
- 兩好球保護區：預設好球帶寬、高的 115%，可調 100–135%。
- 好球帶／區域可隱藏；練習前及回饋時仍會顯示，方便確認設定。
- 可選內建合成提示音，沒有下載外部音效；音效不承擔必要資訊。
- 回饋預設手動前進，可選顯示 4 秒後自動開始下一球。
- 同組重試沿用設定和投球種子；「新一組」產生新種子並返回設定。

### km/h 換算方式

以標準全尺寸球場的投手板至本壘距離 **18.44 米**作固定參考：

`等效球速（km/h）= 18.44 ÷ 飛行秒數 × 3.6 = 66384 ÷ 飛行毫秒數`

| 設定 | 飛行時間 | 等效球速 |
|---|---:|---:|
| 教學 | 2.6 秒 | 約 25.5 km/h |
| 標準 | 1.8 秒 | 約 36.9 km/h |
| 進階 | 1.1 秒 | 約 60.3 km/h |
| 最快自訂時間 | 0.7 秒 | 約 94.8 km/h |
| 最慢自訂時間 | 5 秒 | 約 13.3 km/h |

這是以固定距離除以動畫時間得到的**等效平均速度**。真實球的放球點在投手板前方，且飛行時會減速；本版沒有加入放球延伸、空氣阻力、不同球場距離或透視物理校準，所以數值不是測速槍的出手球速。動畫時間仍為訓練參數，不是生理反應標準。訓練畫面顯示等效球速及決策截止時間；JSON 每球及 CSV 增加 `equivalentSpeedKmh`、`referenceDistanceM`，便於核對。原有本機設定及紀錄繼續可讀。

## 區域、球路及答案

採中性打者視角，未假設打擊慣用手，也未加入使用者角色或球隊徽章。畫面中的向量人物為通用投手。

全場標準化座標為 0–1；x 由左向右，y 由上向下。SVG 固定 viewBox 為 1000 × 560，縮放／旋轉時球及所有區域共同縮放：

- 固定模擬好球帶：`x = 0.36…0.64`、`y = 0.34…0.78`，矩形邊界包含在內。
- 可攻擊區和保護區都以 `(0.50, 0.56)` 為中心，依獨立的寬、高比例縮放。
- 危險區的簡化定義：`(x < 0.20 或 x > 0.80) 且 y < 0.62`。中性視角保守地把兩側近身區都視為應優先避球；不是對真實人體位置的量測。
- 一般模式：可攻擊區內建議 GO，其餘建議 NO。
- 兩好球：保護區內建議 GO，其餘建議 NO。
- 危險球：一律建議 NO，安全優先。

每組開始前就以種子建立全組球路和答案，不會因玩家按 GO／NO 而改變。相同種子及設定可產生相同序列。採用分層抽樣涵蓋中央、好球帶邊緣、區域附近及帶外球；比例極端、球數較少或自訂區域大小時，不保證每組包含所有分類。

球由固定出手位置平滑沿直線接近預先設定的本壘落點，球體逐漸放大。各種裝置使用同一份標準化座標。正式訓練在球抵達前不會以顏色或文字透露答案，只有預先設定的區域線；回饋才標示真實落點和評分。

## 回饋與統計

選擇後即鎖定該球；等球飛到本壘再揭示評分。超過截止仍未選擇，記錄為「未及時決定」，`userChoice`、`reactionMs` 均為 `null`，不會代選 NO。

| 指標 | 定義 |
|---|---|
| 決策準確率 | 正確 GO／NO 數 ÷ 有效 GO／NO 作答數 |
| 追打率 | 有效作答中，建議 NO 卻選 GO 的球數 ÷ 建議 NO 的球數 |
| 錯失攻擊機會率 | 有效作答中，建議 GO 卻選 NO 的球數 ÷ 建議 GO 的球數 |
| 平均反應時間 | 有效作答的反應時間平均，由球出手起計，扣除暫停時間 |
| 未及時決定 | 未在截止前明確選擇的球數，另列，不混入有效作答分母 |

兩好球時，上述「區內／區外」均以當組保護區為準。危險球屬建議 NO 的球；若選 GO，計入追打率，並以獨立「危險球選 GO」錯誤呈現。所有分母為零的比率及沒有作答的平均時間，都顯示「未有樣本」。

總結另列追打壞球、追打區外好球、錯失攻擊／保護機會及安全提醒，並提供逐球回顧、只看失誤／逾時篩選和下一組建議。兩好球放過保護區內來球只提示風險，不直接判三振。按 GO 不會被描述為安打、實際擊中或揮空。

## 本機紀錄及匯出

- `localStorage` 鍵名：`yyn-trainer-v1`，包含版本、設定及最多最近 40 組完整訓練。
- 設定在調整時保存；完整一組在最後一球回饋時保存。中途離開／重新整理的未完成一組不會續練。
- 首頁可查看／重試紀錄、匯出全部 JSON、清除紀錄。清除不影響設定；清除前會確認。
- 總結提供本組 JSON 和 CSV。JSON 包含設定、種子、時間、每球座標、各區域判定、答案、選擇、錯誤類型及反應時間。從當前練習總結匯出的 JSON 也保留原始投球序列。
- CSV 使用 UTF-8 BOM、CRLF 和完整引號，可供 Excel／試算表使用；逾時以 `TIMEOUT` 表示。儲存格會防止以 `= + - @` 等開頭的文字被當作公式。
- 紀錄不會上傳任何伺服器。無痕模式、瀏覽器清理、變更網址／檔案路徑可能令紀錄無法保留或變成另一個儲存空間。
- 瀏覽器對 `file://` 的儲存政策各異。讀寫失敗會顯示提示，但仍能訓練並匯出；此時紀錄只留在目前頁面的記憶體，離開前請匯出。
- V1 只提供匯出，不提供匯入歷史紀錄。

## 開發檢查與測試結果

在網址／本機檔案地址後加 `?debug=1`，會於訓練畫面下方顯示當球種子、最終座標、好球／攻擊／保護／危險旗標及標準答案。這會提前顯示答案，僅供驗證使用；正式預設關閉，也不會保存為訓練設定。

該模式另有唯讀取樣及純函式工具 `window.YYN_DEBUG`：`snapshot()`、`generate(settings)`、`classify(point, settings)`、`stats(records)`、`rate()`、`normalize()`、`csv(session)`。正常開啟時不提供此介面。

已使用 Chromium + Playwright 自動化操作、虛擬時間及截圖檢查：

- 完整 20 球標準模式，鍵盤 GO／NO、正確及錯誤選擇、逐球回饋及總結。
- 截止前有效作答、截止後拒絕作答、逾時獨立計分。
- 快速重複按鍵不重複計分；READY 及暫停期間不接受作答。
- 暫停後動畫時間不增加，恢復後反應時間不包含暫停。
- 重設／取消確認後的回合狀態。
- 相同種子重現；0%、60%、100% 好球比例。
- 攻擊區、好球帶邊緣、保護區內外、危險球分類。
- 畫面最終落點標記與原始生成座標完全一致。
- 本機紀錄重新載入；JSON／CSV 實際下載及內容檢查。
- iPad 尺寸觸控模擬及橫向／直向旋轉；390 px 手機寬度無橫向溢出。
- 儲存被瀏覽器拒絕時，提示及訓練仍可用。
- 關閉區域線時，投球期間隱藏、回饋才重現；自動下一球的暫停／恢復。
- 全組 10 球逾時時，四項指標均顯示「未有樣本」，逐球紀錄完整。
- 清除紀錄／取消清除，以及自訂時間等設定在重開後保留。
- km/h 換算、時間／球速雙向輸入、輸入界限、生成後的真實飛行時間、匯出欄位及重開後球速設定。
- 正常網址不暴露 debug 工具；測試未有 JavaScript 例外。

**測試範圍說明：**雲端測試環境的 Chromium 管理政策禁止 `file://` 導航（`ERR_BLOCKED_BY_ADMINISTRATOR`）。因此採用 Playwright 攔截本機來源 HTML，並在瀏覽器離線狀態完成測試，沒有請求外部資源。這驗證了離線執行及內嵌資源，但不等於已在該環境成功雙擊本機檔案。iPad 測試為 Chromium 的尺寸及觸控模擬，未使用實體 iPad／Safari。全螢幕及實際喇叭音效亦取決於裝置，未作實體裝置驗收。

## 已知限制及後續方向

- 此為 2D 視覺判斷練習；不量度真實揮棒、身體動作、擊球率或球棒速度。
- 只有合成直線球路，沒有完整物理、真實球種或裁判好壞球模型；好球判定以球心是否落入矩形為準，未加入球半徑擦邊判定。
- 區域可調大小，V1 未提供拖動中心點、自由繪製熱區或左／右打視角切換。
- V1 不推進打席 Balls／Strikes、不模擬安打或三振、不作趨勢圖或球區分組分析。
- 裝置幀率、輸入延遲及瀏覽器排程會影響毫秒數值；不可當作專業反應時間量測器。
- 沒有帳戶、雲端同步、連線對戰、排行榜、相機追蹤或 PWA 離線安裝。
- V1.1 可加入打席球數、球區分組、跨組趨勢、JSON 匯入、可移動攻擊區、更多連貫球路及真機 Safari 驗收。
